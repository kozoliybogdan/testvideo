# Страница-воспоминание

Готовая статическая страница с видео для открытия по QR-коду. Работает без backend, базы данных, Node.js и сторонних библиотек.

## Структура

```text
/
├── index.html
├── style.css
├── script.js
├── video.mp4
├── favicon.png
└── README.md
```

## Как добавить своё видео

1. Подготовьте ролик в формате MP4. Для лучшей совместимости используйте видео H.264 и звук AAC.
2. Назовите файл `video.mp4`.
3. Положите его в корень проекта — рядом с `index.html`.
4. Замените существующий демонстрационный `video.mp4`, не меняя имя.

Желательно сжать ролик перед публикацией: так страница быстрее откроется через мобильный интернет. Вертикальные и горизонтальные видео отображаются целиком благодаря `object-fit: contain`.

## Как проверить локально

Самый простой способ — открыть `index.html` двойным щелчком. Для проверки поведения, максимально близкого к опубликованному сайту, запустите локальный HTTP-сервер из папки проекта.

Если установлен Python:

```bash
python -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`.

Чтобы проверить страницу на телефоне в той же Wi-Fi сети, узнайте локальный IP-адрес компьютера и откройте `http://IP-АДРЕС:8000`. Брандмауэр может запросить разрешение на доступ.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все шесть файлов из проекта.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. После публикации GitHub покажет адрес вида `https://ИМЯ.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

У GitHub есть ограничение на размер одного загружаемого файла. Если видео слишком большое, предварительно уменьшите его размер.

## Публикация на Cloudflare Pages

### Через GitHub

1. Сначала загрузите проект в репозиторий GitHub.
2. В панели Cloudflare откройте **Workers & Pages** и создайте новое приложение Pages.
3. Подключите GitHub и выберите репозиторий проекта.
4. Для типа проекта выберите статический сайт. Команду сборки оставьте пустой, каталог результата укажите `/` или оставьте значение по умолчанию для корня репозитория.
5. Запустите публикацию. Сайт получит адрес вида `https://имя-проекта.pages.dev/`.

### Прямая загрузка

В Cloudflare Pages также можно выбрать загрузку готовых файлов и перетащить содержимое папки проекта. Загружайте сами файлы, чтобы `index.html` находился в корне опубликованного сайта.

## Netlify и Vercel

Проект не требует настроек сборки. В Netlify можно перетащить папку проекта в форму ручного развёртывания. В Vercel достаточно импортировать Git-репозиторий и выбрать статический проект без build command.

## Какую ссылку поместить в QR-код

Используйте полный публичный HTTPS-адрес опубликованной страницы:

- GitHub Pages: `https://ИМЯ.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`
- Cloudflare Pages: `https://имя-проекта.pages.dev/`
- либо подключённый собственный домен.

Перед печатью QR-кода обязательно откройте эту ссылку на iPhone и Android через мобильный интернет, проверьте звук и досмотрите видео до конца. Не используйте локальный адрес `localhost` или адрес файла на компьютере — с другого устройства они не откроются.

## Что можно изменить

- Заголовок: текст внутри `<h1>` в `index.html`.
- Подпись: элемент с классом `dedication` в `index.html`.
- Видео: замените `video.mp4` или измените `src` у тега `<video>`.
- Фон и цвета: переменные в начале `style.css`, прежде всего `--bg`, `--surface` и `--accent`.
- Максимальная ширина плеера: переменная `--player-width` в `style.css`.
- Скругление плеера: переменная `--radius` в `style.css`.

## Поведение на iPhone и Android

Видео не пытается автоматически запускаться со звуком: мобильные браузеры обычно блокируют такое воспроизведение. Большая кнопка **«▶ Посмотреть»** является явным пользовательским действием, после которого видео запускается со звуком. Атрибуты `playsinline` и `webkit-playsinline` оставляют видео внутри страницы на iPhone. После запуска появляются стандартные элементы управления, поэтому видео можно поставить на паузу; после окончания доступна кнопка повторного просмотра.
